# CS501 Assignment 4 - Q3 Polyline and Polygon

This project is a simple Android app built with Kotlin and Jetpack Compose.

## What the app does

- displays a Google Map  
- shows a polyline representing a hiking trail  
- shows a polygon highlighting an area  
- allows changing the color and width of the polyline  
- allows changing the color of the polygon  
- displays information when the user taps the trail or the area  

## How to use

1. Run the app  
2. Use the buttons to change line color and thickness  
3. Use the buttons to change area color  
4. Tap the blue line → shows trail info  
5. Tap the green/yellow area → shows area info

- `AndroidManifest.xml`
